# Key-pose sprite sheet prompts: every symbol (Gemini)

Written 2026-11-17 for Darshan (generated by `tools/asset-pipeline/make_keypose_prompts.py`; edit the script and rerun to change all prompts at once). One prompt per symbol, complete and ready to paste. **Attach that symbol's tile image (the file named under each heading) every time.**

## How to get a usable sheet from Gemini
1. New chat for each symbol (Gemini carries style drift across a chat). Attach the symbol tile, paste the prompt.
2. Check the sheet before sending it: 16 panels, 4×4, same tile size, text spelled right, nothing outside the tiles. If one of these fails, reply with the matching fix line below instead of starting over.
3. If Gemini can't hold 16 consistent panels, ask for panels 1–8 as a 4×2 grid, then 9–16 as a 4×2 grid (attach the reference both times). Send me both images.
4. Don't worry about the small Gemini sparkle logo in the corner: the last panels are replaced with panel 1 when I build the loop.

**Fix lines** (reply in the same chat):
- Wrong panel count: `Wrong: the grid must be exactly 4 columns x 4 rows = 16 panels. Regenerate.`
- Tile or background changed: `The frame, rivets and background must be identical to the reference in all 16 panels; only the described change may differ. Regenerate.`
- Subject moved or resized: `Locked camera: the subject must stay the same size and position in every panel. Regenerate.`
- Text misspelled: `The text must read exactly as in the reference in every panel, letter for letter. Regenerate.`
- Too little happening: `Make the flash, glow and effects in panels 6-10 bigger and brighter, keeping the subject unchanged. Regenerate.`

## Why the prompts are written this way
- **Drama comes from light and effects, not redraws.** Gemini redraws a subject slightly differently each time, which shows as wobble. So the subject stays put and the drama is flashes, glints, smoke and sparks drawn over it, with only small squash, tilt or hop moves.
- **Each story has a shape:** idle → anticipation → build-up → flash (the climax) → hold → settle → back to idle. Panel 16 = panel 1, so the loop is seamless.
- **Timing** (frames at 30 fps, 75 = 2.5 s) is applied by me when I build the animation: quick on the flashes, long on the holds.
